# My skin recipes

These optional CSS snippets are examples for the owner-managed `Skins/My skin/skin.css` file served by the Files API. They are not built-in skins and are never loaded by Wizard OS automatically.

Copy only the rules you want into **Files → Skins → My skin → skin.css**. Preserve any existing rules. The shell sanitizes the file and layers it after the selected skin.

- [`orb-control-contrast.css`](orb-control-contrast.css) pairs the phone orb controls with the active palette’s foreground and opaque background, including active, paused, focus, and attachment-count states.
