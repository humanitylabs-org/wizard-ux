- **Orb second enable:** round7 `3-desktop-nebula-miguel-orb-shell` at `toggle:miguel/orb-shell:true:still-open-retap` retained the same root, window ID, non-hidden property and rectangle, but was not visible. The failure screenshot contains Orb and Chats, no Settings. Promote the existing open root for Home takeovers too, exactly as explicit `openSettings` already does. Demote it when the desk returns. No close/reopen, replacement root, new listener or Look-page reset.
- **AI apps flash:** the window-to-modal move was already reparenting the same root without setting `hidden`, but adding `.is-modal` replayed `st-pop`, whose first keyframe is `opacity: 0`. Round7 sampled a closed-looking root at the modal rectangle before the final correct screenshot. Mark an already-visible promotion `is-rehosted` before reparenting, and disable only that entrance animation. Remove the marker on demotion/dismissal; genuine modal opens retain their animation. Keep strict mutation/frame continuity checks: no harness grace period or host-move exception.
- **Shared look convergence was a harness routing defect:** round7 intercepted `/apps/pages/api/file?path=settings/look.json`; the product requests `GET/PUT /wizard/v1/pages/wizard-look/look.json`. Its read ledger shows that real path falling through to synthetic `{}` responses (status 200, no text), so sync went offline, pending views were never saved, and the seeded document stayed desktop AI apps at 2 / phone Orb at 3. `forwardedWrites: 0` is safety evidence, not evidence of a successful save. The expected final desktop Apps / phone Desks is correct. Use a shared synthetic adapter at the actual path, with string versions, 409/current responses and persisted write ledger. Browser gate additionally requires actual reads, accepted writes from each device, advancing revisions, `last: ok`, and both local projections matching the stored document. The routing repair itself leaves merge semantics alone; the separate early-choice repair below extends causal basing.

- **Previously synced early choice (Oscar for Miguel):** [original finding A](https://github.com/humanitylabs-org/wizard-ux/pull/963#discussion_r4466817439), **2026-11-04T11:23:09Z**. Track unbased view intents (including restored pending storage), stamp each once after observing GET/409, and overlay newer pending views when adopting a successful older PUT. Do not restamp already-sent intent on each 409: a genuinely newer conflicting server edit still wins. Both-shell merge remains per-field, preserving concurrent other-shell edits. This is a separate source defect from the proven round7 wrong-route failure; both are repaired without treating either as evidence for the other.
